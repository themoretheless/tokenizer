# План улучшения языков (Rush / rush-lang / Forma)

Тема: **честность и завершённость**. Принципы:

1. Улучшение усиливает центр языка, а не размывает его
   (rush-lang — fixed-size/no_std дисциплина; Rush — предсказуемая песочница;
   Forma — статические гарантии и редакторский DX).
2. Осознанные границы фиксируем как решения, а не как долг.
3. Диагностика, которой можно верить, важнее новых фич — тот же стандарт
   «capability honesty», что репозиторий применяет к движкам подсветки.

### T0.2 Forma: закрыть дыру `Record<K, V>`

`src/semantics.rs:421-431` — `matches_type` проверяет только значения, `K`
ни с чем не сопоставляется. JSON-ключи всегда строки, поэтому:

- `validate_type_name` (`semantics.rs:364-376`): отклонять
  `Record<K, V>` с `K != String` явной диагностикой («ключи Record — всегда
  String»), а не тихо принимать `Record<Int, …>`.
- `matches_type`: поведение не меняется (объект матчится по значениям),
  документируем `K` как фиксированный `String`.

Приёмка: тест на `Record<Int, Number>` → понятная ошибка;
`Record<String, Int>` работает как раньше.

- Задокументировать поддерживаемое подмножество (альтернатива `|` только

Приёмка: катастрофический паттерн в constraint даёт диагностику с кодом;

## PR-2. rush-lang stage 6: `break` / `continue` / `else if`

`crates/rush-lang` — единственная дыра в управлении потоком.

- `break` / `continue` в `for`/`foreach`: флаг управления в replay-кадре
  (`PendingFrame`); `break` завершает тело цикла, `continue` — итерацию.
  Вне цикла — новый вариант `RushError` (стабильные коды, как принято в
  крейте). Инварианты `no_std` / zero-alloc / fixed-size не трогаем:
  ни одна `MAX_*` константа не растёт без явной необходимости.
- `else if <cond>:` — расширение кадра `Else` (`lib.rs:147-152`): парсится
  как вложенный `If` с общим учётом `taken`.
- Doc-комментарий `lib.rs:4-16` дополняется моделью stage 6.

Приёмка: `cargo test -p rush-lang` зелёный, включая новые тесты в
`tests/lang.rs` по образцу существующих (stage-нумерация в именах);
`#![deny(unsafe_code)]`, без `alloc`.
